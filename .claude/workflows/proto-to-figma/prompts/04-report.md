# result.md 작성

`입력`으로 받은 캡처 결과, 연결 결과, 도달 불가 화면 목록을 사람이 읽을 `result.md`로 정리해 Write 도구로 `입력 > 저장 경로`에 저장하라.

`입력 > 캡처 결과`의 각 항목은 id만 갖고 이름은 없다 — 화면 이름이 필요하면 `입력 > 화면 목록`(전체 화면 객체 배열, id/name 포함)에서 같은 id를 찾아 조회하라. `입력 > 도달 불가 화면`은 이미 id/name/note를 포함한 화면 객체 배열이므로 별도 조회 없이 그대로 쓴다.

구성:
1. 요약: 캡처 성공/실패 수, 연결 성공/실패 수, 도달 불가 화면 수
2. 화면별 표: id, 이름(`입력 > 화면 목록`에서 조회), Figma 노드 id 또는 "실패", 실패 사유(있으면)
3. 연결 실패 목록: from, to, 사유
4. 도달 불가 화면 목록: id, 이름, 비고 (`입력 > 도달 불가 화면`의 name/note를 그대로 사용)
5. 맨 아래에 `입력 > figmaUrl`

저장 후 `{ ok: true }`를 반환하라.
