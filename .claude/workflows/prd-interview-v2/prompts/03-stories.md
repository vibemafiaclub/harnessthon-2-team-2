# 유저스토리 + 인터뷰 질문 생성

먼저 Read 도구로 `입력 > PRD 경로`의 PRD 원문을 읽어라.

`입력 > 페르소나`의 유저스토리를 3~6개 써라.
- 형식: "<역할>로서, <상황>에서 <행동>을 하고 싶다. 그래야 <목적>이기 때문이다."
- 각 스토리에 관련 기능 id(featureIds)를 `입력 > 기능 목록`에서 골라 붙인다.
- 이 페르소나가 실제로 마주칠 까다로운 경우(PRD의 "사용자들의 상황" 항목)를 스토리에 반영하라.

각 스토리당 시나리오형 인터뷰 질문 1~2개를 만들어라.
- 라벨형 질문("직관적이면 좋겠나요?") 금지.
- "~한 상황이라고 해봅시다. 그때 어떻게 하시겠어요?" 식으로.

결과 파일은 Write 도구로 `입력 > 저장 경로`에 저장하라 (한국어, 스토리와 질문 모두 포함).
