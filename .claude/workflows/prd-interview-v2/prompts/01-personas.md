# 페르소나 추출

먼저 Read 도구로 `입력 > PRD 경로`의 PRD 원문을 읽어라.

PRD에 등장하는 서로 다른 역할/사용케이스마다 페르소나를 **정확히 1명씩** 만들어라. 역할은 PRD의 유저스토리·배경·상황에서 뽑는다 (예: 예비신부, 예비신랑, 초대받은 지인). 같은 역할을 여러 명 만들지 마라.

각 페르소나는 실존하는 사람처럼 구체적으로:
- 이름
- 상황 (직업, 나이대, 준비 단계, 인간관계 규모 등)
- 기술 숙련도
- 이 제품으로 달성하려는 목적 (JTBD 형식: "~할 때 ~하고 싶다, 그래서 ~하기 위해")
- 지금 쓰는 대안
- 좌절 포인트 2~4개

PRD가 놓치고 있을 법한 역할이 있으면 1명까지 추가해도 된다. 추가했다면 context에 그 이유를 적어라.

slug는 ascii 소문자/하이픈으로 (파일명에 쓴다).

결과 파일은 Write 도구로 `입력 > 저장 경로`에 저장하라 (마크다운, 페르소나별 섹션, 한국어).
