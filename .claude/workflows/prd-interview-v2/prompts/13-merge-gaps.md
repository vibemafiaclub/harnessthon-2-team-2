# 빠진 플로우 병합

`입력 > 빠진 항목`은 페르소나별 여정에서 나온 빠진 화면·플로우 목록이다 (persona 필드가 출처). 같은 플로우를 여러 페르소나가 다른 말로 적었을 수 있다.

- 실질적으로 같은 플로우는 하나로 합친다. summary에 어느 페르소나들에게 필요한지 남긴다.
- `입력 > 기능 목록`에 이미 있는 것은 뺀다.
- mode는 합친 항목들 중 하나라도 interview면 interview.
- baseline이면 proposal을 하나로 정리하고, 소유자 결정이 필요한 갈림길이 있으면 question과 options를 남긴다 (여러 개면 가장 중요한 하나).
- id는 F0-1, F0-2… 순번.

결과를 Write 도구로 `입력 > 저장 경로`에 저장하라 (마크다운, 항목별 섹션: id / 이름 / mode / 어디서 필요한지 / 제안 / 소유자 결정 필요 사항, 한국어).
